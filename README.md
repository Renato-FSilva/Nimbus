# Nimbus — clima e mobilidade

Aplicação web de clima com cidade e estado, condições para atividades e consulta de status dos trens e metrô de São Paulo. O front-end está em `public/` e as funções serverless Netlify ficam em `netlify/functions/`.

## Publicar

### GitHub

Crie um repositório chamado `Nimbus` e envie o conteúdo desta pasta para ele. Não envie tokens ou arquivos `.env`.

### Netlify

Importe este repositório no Netlify. A configuração em `netlify.toml` aponta a pasta publicada para `public` e as funções para `netlify/functions`.
